# System Software Lab. website

A modern, responsive static website for the System Software Lab., Inha University.

## Files
- `index.html` — all website content
- `styles.css` — visual design and responsive layout
- `script.js` — mobile menu + current year

## Preview locally
Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages
1. Create a new GitHub repository (for example, `system-software-lab`).
2. Upload the three website files to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch** and select `main` / root.
4. GitHub will publish the site automatically.
